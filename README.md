# AnotherMe

AnotherMe is a local-first personal mirror agent. It helps you record experiences, choices, motives, and outcomes, then uses those memories to reflect on important decisions and simulate possible future branches.

It is not a fortune-telling tool, and it does not make decisions for you. Its purpose is to help you see your own patterns more clearly: how your past self tends to choose, what you may actually be torn about, which blind spots keep repeating, and what small action you can take next.

## Features

- Daily logs: save natural-language reflections and extract structured memories
- Personal mirror: review values, behavior patterns, fears, desires, goals, and blind spots
- Decision simulation: compare A/B options across 1-year, 3-year, and 10-year branches
- Future-self letters: generate letters grounded in your actual memory base
- Timeline: review logs, choices, and outcomes over time
- Local-first storage: memories, logs, and model settings stay on your device
- Multi-provider AI: supports OpenAI-compatible APIs such as OpenAI, DeepSeek, Qwen, and Kimi

## Download the Desktop App

Windows builds are generated by GitHub Actions.

1. Open the repository's Actions page
2. Open the latest `Build Desktop App` run
3. Download the `another-me-windows` artifact at the bottom of the page
4. Unzip it and run either the installer or the portable app

Installer file:

```text
AnotherMe Setup 0.1.0.exe
```

Portable file:

```text
AnotherMe 0.1.0.exe
```

When you open the app for the first time, go to `API Settings` and enter your model provider configuration.

## AI Provider Configuration

AnotherMe uses the OpenAI-compatible `/chat/completions` API format. Any provider with a compatible endpoint can be used by entering:

```text
Base URL
API Key
Model name
```

Common examples:

| Provider | Base URL | Example model |
| --- | --- | --- |
| OpenAI | `https://api.openai.com/v1` | `gpt-4.1-mini` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| Qwen | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| Kimi | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |

Your API key is saved locally only. It is not committed to the repository and is not uploaded to GitHub.

## Run Locally

Install Node.js first, then run:

```bash
npm install
npm run dev
```

Open:

```text
http://localhost:3000
```

## Local Data

In local web development, data is stored in:

```text
data/another-me-state.json
data/settings.json
```

In the desktop app, data is stored in the system user data directory under `data/`.

These files are ignored by Git and are not included in the GitHub repository.

## Build the Windows App

```bash
npm run dist:win
```

Build outputs are written to:

```text
release/
```

The repository also includes a GitHub Actions workflow. Pushing to the `main` branch automatically builds Windows `.exe` files and uploads them as an artifact.

## Safety Boundaries

AnotherMe does not provide medical diagnoses, legal conclusions, investment buy/sell recommendations, or deterministic life advice.

If a user expresses self-harm, suicidal intent, or severe hopelessness, the app switches to safety-support mode and encourages the user to contact trusted people or local emergency support.
