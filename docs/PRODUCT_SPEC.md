# 世另我产品规格

世另我是一个长期学习用户经历、决策、动机和结果的个人镜像 Agent。它不是替用户做决定，而是基于“过去的用户”，模拟“未来可能的用户”，帮助用户在关键选择前看见不同人生分支。

## MVP 范围

第一版只验证一个问题：

> 用户看到世另我的分析后，会不会觉得：“它真的有点像我。”

MVP 包含：

- 每日记录
- 结构化记忆提取
- 我的镜像
- 重大决策 A/B 输入
- 未来分支模拟
- 未来来信
- 基础安全边界

MVP 不包含：

- 支付
- 社交分享
- 浏览器插件
- 微信记录自动解析
- 数字人形象
- 本地大模型接入
- 多租户企业版

## 产品原则

- 不宣称预测命运
- 不替用户做最终决定
- 重要判断必须给出依据
- 用户拥有记忆控制权
- 高风险领域只做辅助分析
