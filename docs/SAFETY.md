# 安全边界

世另我不做确定性人生建议，不预测命运，不替用户决定重大事项。

## 高风险场景

以下场景必须进入谨慎模式：

- 自杀、自伤、极端心理危机
- 医疗
- 法律
- 投资、借贷和重大财务决策
- 婚姻、生育、辞职、创业等高影响选择

## 危机场景

如果用户表达自杀、自伤或强烈绝望，系统停止未来模拟，转为安全支持模式：

```text
我很在意你现在的安全。这个问题不适合只由 AI 陪你处理。请立刻联系身边可信任的人，或联系当地紧急服务/心理危机热线。
```

## 投资场景

禁止输出买入、卖出、一定赚钱、一定暴涨等内容。允许做风险承受能力分析、仓位压力模拟、最坏情况模拟和盲区提醒。

## 模拟交易

A 股模拟器（`/trading`）只使用虚拟资金。逐笔复盘评价的是交易过程（计划、仓位、情绪），不预测股价、不推荐买卖。蒸馏出的策略是用户自己历史行为的规则化总结，只在模拟策略账户中运行，并始终附带样本内偏差和不确定性说明。交易日志中出现借贷、杠杆、梭哈、回本等信号或危机类表达时，经 `src/lib/safety/classify-risk.ts` 的 `classifyTradingRisk` 给出安全提示。
