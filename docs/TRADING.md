# A 股模拟交易（A-Share Simulator）

入口：应用首页导航栏 `A-Share Sim`，或直接访问 `/trading`。

## 目标

1. 用虚拟资金模拟 A 股交易，规则尽量贴近真实市场。
2. 每一笔交易都写交易日志（理由、情绪、信心、止损/止盈），系统逐笔复盘「过程」而不是「结果」。
3. 平仓交易积累到足够数量后，从**你自己的交易**中蒸馏出一套明确的规则策略，在独立的策略账户里自动模拟交易，用来对比「我」和「去掉情绪后的我」。

## 已实现的 A 股规则（`src/lib/trading/rules.ts`）

- T+1：当天买入的股份次一交易日才能卖出
- 买入数量：主板/创业板 100 股整数倍；科创板最少 200 股；北交所最少 100 股
- 卖出零股必须一次性卖完
- 涨跌停：使用行情源给出的涨停价/跌停价；封涨停（无卖盘）买不进，封跌停（无买盘）卖不出
- 成交价：买入按卖一价，卖出按买一价
- 费用：佣金 0.025%（最低 5 元）、印花税 0.05%（仅卖出）、过户费 0.001%
- 交易时间：默认只在北京时间 09:30-11:30、13:00-15:00 成交；节假日通过「行情日期是否为今天」识别（可在设置中关闭）

## 数据源（`src/lib/trading/market-data.ts`）

- `tencent`：腾讯公开行情接口（实时报价 + 前复权日 K）。非官方接口，可能延迟或变更。
- `mock`：离线生成的假价格，仅用于试用，界面会明确标注，不应从中学习模式。

## 模块

```text
src/lib/trading/
  types.ts            数据结构（全部带 userId）
  rules.ts            A 股规则、费用、交易时间
  market-data.ts      行情（服务端）
  features.ts         交易时的市场特征（涨幅、均线偏离、动量、量比、距涨停等）
  engine.ts           撮合引擎（纯函数）
  analytics.ts        买卖配对（FIFO）与绩效统计
  trade-reviewer.ts   规则化逐笔复盘
  distiller.ts        策略蒸馏
  backtest.ts         日线回测（T+1、涨跌停、费用）
  strategy-runner.ts  策略账户的一轮决策
  service.ts          服务端用例，API 路由只做转发
  store.ts            data/trading-state.json 读写（串行化写入）
```

AI 提示词集中在 `src/lib/ai/prompts.ts`（`tradeReviewPrompt`、`strategyExplainPrompt`）。未配置 API Key 时使用规则化复盘。

## 策略蒸馏怎么做

1. 至少 20 笔已平仓交易（同一笔买入分批卖出只算一笔）。
2. 对每个市场特征按三分位找阈值，贪心选出最多 3 个条件，使命中交易的平均收益明显高于整体，且每个条件至少覆盖 25%（且不少于 6 笔）的样本。
3. 止损 = 命中交易中亏损的中位数，止盈 = 盈利的中位数，最长持有 = 盈利交易持有天数的 75 分位，仓位 = 你自己仓位的中位数（限制在 5%-20%）。
4. **情绪不作为策略输入**：策略只看市场条件和固定的出场规则，从而去掉 FOMO、恐惧、报复性交易。
5. 用约一年的日线数据回测，并列出样本内偏差等警告。
6. 草稿需要手动「Activate」，之后可手动运行一轮，或在页面打开期间每 5 分钟自动运行（仅交易时段）。

## 边界

- 只在模拟账户里交易，不接券商、不动真实资金。
- 样本内统计偏乐观；几十笔交易得出的模式可能只是运气。所有输出都附带不确定性说明。
- 交易日志里出现借钱、加杠杆、梭哈、回本等字样时，复盘会附带安全提示（`classifyTradingRisk`）。
